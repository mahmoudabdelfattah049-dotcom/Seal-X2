# Seal X2 — بوابة العلوم المتكاملة

منصة عربية RTL موجهة أساسًا لمادة **العلوم المتكاملة**، بإشراف أساسي من **مستر محمد عمارة**. مبنية باستخدام HTML/CSS/JavaScript وSupabase.

## الموجود حاليًا
- تسجيل حسابات الطلاب بالبريد الإلكتروني وكلمة المرور عبر Supabase Auth.
- كل حساب جديد يحصل تلقائيًا على دور `student`.
- منشئ امتحانات اختيار من متعدد: إضافة سؤال منفصل، 4 اختيارات، تحديد الصحيح، درجة لكل سؤال، مدة، ونسبة نجاح.
- إعدادات الامتحان: ترتيب أسئلة عشوائي، السماح بمحاولات متعددة أو محاولة واحدة، وإظهار النتيجة أو إخفاؤها.
- تصحيح وحفظ النتائج على الخادم، مع منع الطالب من قراءة درجات الامتحانات المخفية عبر استعلامات قاعدة البيانات المباشرة.
- لوحة طالب للمحاولات والنتائج المسموح بعرضها.
- لوحة مدرس لإنشاء الامتحانات ونشر الإعلانات وإضافة روابط تعليمية وإدارة حالة نشر الامتحانات.
- لوحة مالك المنصة لإدارة أدوار الحسابات.
- صلاحيات قاعدة البيانات محمية بـ RLS. المدرس لا يستطيع تعديل أو حذف موارد المكتبة؛ يمكنه إضافة مورد جديد فقط. الحذف الإداري للموارد محصور في المالك/المدير.

## الأدوار
- `student`: حل الامتحانات المنشورة ومتابعة محاولاته.
- `teacher`: حساب مدرس واحد فقط؛ إدارة الامتحانات والأسئلة والإعلانات وإضافة مصادر، دون تعديل أو حذف مصادر المكتبة.
- `admin`: صلاحيات إدارة المحتوى والحذف الإداري.
- `owner`: مالك المنصة؛ كل صلاحيات الإدارة وإدارة أدوار الحسابات.

قاعدة البيانات تمنع وجود أكثر من حساب واحد بدور `teacher` في الوقت نفسه.

## إعداد أول حساب مالك
لا يوجد مفتاح دخول عام أو كلمة مرور رئيسية ثابتة داخل الموقع. هذا النوع من المفاتيح يمكن لأي شخص يراه أن يستولي على المنصة، كما أن كود الدخول الذي يُكتب في ملفات JavaScript يصبح مكشوفًا لكل زائر.

1. أنشئ حسابًا عاديًا من شاشة التسجيل باستخدام بريد تملكه وكلمة مرور قوية.
2. بعد تأكيد الحساب، افتح Supabase → SQL Editor.
3. استبدل `AUTH_USER_UUID` بمعرّف الحساب الصحيح من Authentication → Users ثم نفّذ:

```sql
update public.profiles
set role = 'owner', display_name = 'إدارة المنصة'
where id = 'AUTH_USER_UUID';
```

لا تنفذ الأمر إلا للحساب الذي تملكه وتحققت من UUID الخاص به. لا تضع كلمة المرور في الكود أو في المستودع.

بعد تسجيل الدخول بهذا الحساب ستظهر إدارة الحسابات. يستطيع المالك تحويل حساب مستر محمد عمارة إلى `teacher`. القيد الفريد يمنع تعيين مدرس ثانٍ.

بعد النشر، اضبط Supabase Auth Site URL وRedirect URLs على رابط GitHub Pages الفعلي.

## حدود النسخة الحالية
- مدة الامتحان تظهر للطالب كإرشاد؛ لم تُفعّل بعد كحد زمني يفرضه الخادم.
- لا يوجد رفع ملفات فعلي حتى الآن؛ المكتبة تقبل روابط تعليمية.
- لم يكتمل اختبار end-to-end بحساب طالب وحساب مدرس بعد.
